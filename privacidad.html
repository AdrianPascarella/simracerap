Privacy policy

SimRacerAP’s “streamer-project” application · Last updated: 9 October 2026

What the application is

“streamer-project” is a private tool used solely by the owner of the YouTube channel SimRacerAP to manage their own channel. It is not open to the public and is not used by anyone else.

What Google data it uses

With the owner’s express authorization, the application uses the YouTube APIs to access:

  • information about the SimRacerAP channel and its videos, in order to manage them;
  • uploading videos to the SimRacerAP channel;
  • the channel’s YouTube Analytics statistics, in order to analyse its performance.

It does not access data from any other account, nor data about the channel’s viewers beyond the aggregate statistics that YouTube Analytics provides to any channel owner.

Where the data is stored and who it is shared with

The authorization token and the data obtained are stored only on the owner’s personal computer. They are not sold, not transferred to third parties and not used for advertising. Data is sent only to Google, when using its APIs.

How to revoke access

The owner can revoke the authorization at any time from myaccount.google.com/permissions. Once revoked, the application can no longer access the channel. The token stored on the computer can be deleted at any time.

YouTube services

The application uses the YouTube API Services. Their use is subject to the YouTube Terms of Service and the Google Privacy Policy.

Contact

For any questions about this policy, open an issue in this website’s repository.
